# Contributing to Kobun

Kobun is source-available software licensed under [FSL-1.1-MIT](LICENSE). While the source code is publicly available, outside pull requests are not accepted at this time. Bug reports and feature requests are welcome via GitHub Issues.

## Bug Reports

Before filing a bug report, please search [existing issues](https://github.com/aureliushq/kobun/issues) to avoid duplicates.

When opening a new issue, include:

- Steps to reproduce the bug
- Expected behavior vs. actual behavior
- Environment details (browser, OS, Kobun version if known)
- Error messages or screenshots, if applicable

## Feature Requests

Feature requests are welcome. When submitting one, please include:

- The problem the feature would solve
- Your proposed solution
- Any alternatives you considered

## Security Vulnerabilities

If you discover a security vulnerability, do **not** open a public GitHub Issue. Instead, report it via email to [hey@i4o.dev](mailto:hey@i4o.dev).

## Self-Hosting

For questions about self-hosting Kobun, see the [Deployment Guide](DEPLOYMENT.md).
