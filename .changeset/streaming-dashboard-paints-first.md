The dashboard now paints as soon as it knows which Project you are on, instead of waiting for everything it was going to show. Your Drafts fill in behind a placeholder of the right shape, and checking for a new kobun release no longer holds the page up — if that check is slow or never answers, you simply do not see an update notice. Every sidebar destination is now fetched as you move towards it, so the page is usually part-way loaded by the time you click.
