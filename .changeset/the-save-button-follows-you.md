The Save button's choice now follows you, not your browser. Whichever of Save and Save to GitHub you set it to is remembered against your account, so it is the same on your laptop, on your other browser, and after you clear your cookies. It used to be a cookie, which meant a choice you made at your desk was not the one waiting for you anywhere else.

One thing to know: because the old choice was a cookie, this release cannot carry it across. If you had set the button to Save to GitHub, it is Save again the first time you open an editor — set it once more and it stays for good.
